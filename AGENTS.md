# Instructions for coding assistants

This is a **local educational project** that uses fictional trainee records.

- Start by reading README.md, server.py, store.py and web/index.html.
- Explain the frontend -> API/backend -> SQLite flow before proposing changes.
- Suggest a short plan and obtain approval before editing files.
- Keep the starter architecture. Do not install packages unless the tutor approves.
- Use Python standard library, SQLite, and basic HTML/CSS/JavaScript.
- Never add real trainee data, secrets, payments, or external services.
- Do not deploy this application publicly; it lacks authentication and production security.
- Add or improve tests for each feature; report exact test results and limitations.
- Prefer readable code. Explain every change in plain English.

**Tasks are in HOMEWORK_TASK.md**. Do not solve them without the student's request.
